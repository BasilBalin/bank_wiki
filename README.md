# БанкВики

Локальная учебная Википедия для подготовки аналитика вторичных продаж в управляющей компании. Сайт работает на ноутбуке и не требует публикации в интернете.

## Что входит в MVP

- десять связанных учебных статей: восемь основ инвестиций и две статьи об аналитике клиентской базы УК;
- полнотекстовый поиск по статьям и словарю;
- словарь банковских и аналитических терминов, включая цессию;
- обратные ссылки между статьями;
- локальные избранное и отметки изученного;
- тесты с пояснениями;
- карточки для повторения и экспорт в TSV для Anki;
- отдельная адаптивная версия интерфейса для небольшого экрана.

Прогресс и избранное хранятся в браузере на текущем устройстве.

## Локальный запуск

В этой рабочей среде Node.js и pnpm предоставляются Codex. Сначала добавьте их в текущую сессию терминала:

```bash
export PATH="/Users/vasilijbalin/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin:/Users/vasilijbalin/.cache/codex-runtimes/codex-primary-runtime/dependencies/bin/fallback:$PATH"
```

Запустите тестовую версию:

```bash
cd '/Users/vasilijbalin/python/projects/bank_wiki'
pnpm run dev
```

После появления строки `Local: http://localhost:3000/` откройте [http://localhost:3000](http://localhost:3000). Для остановки нажмите `Ctrl+C` в терминале.

Для запуска стабильной копии сначала соберите проект, затем запустите производственный сервер:

```bash
pnpm run build
pnpm start
```

Стабильная версия будет доступна по адресу [http://localhost:3001](http://localhost:3001).

## Модель стабильной копии

GitHub использует одну ветку `main`. Разработка продолжается в основной рабочей папке. Стабильная версия будет находиться в отдельном локальном клоне и обновляться только вручную командой `git pull --ff-only`, поэтому незавершённые изменения не попадут в учебную копию.
